# دليل فتح مشروع Supabase مجاني ونسخ المفاتيح

هاد الدليل لصاحب المشروع. ما بيحتاج أي خبرة بالبرمجة، وما بيحتاج بطاقة ائتمان.
Supabase هو المكان اللي بتنحفظ فيه قاعدة البيانات (الزبائن والمواعيد) وحساب الدخول لسامية.

الوقت المتوقع: 10 دقايق.

---

## الخطوة 1: افتح حساب

1. افتح الموقع: **https://supabase.com**
2. اكبس **Start your project** (فوق على اليمين).
3. سجّل بحساب GitHub إذا عندك، أو **Sign up** بالإيميل وكلمة سر.
4. إذا سجّلت بالإيميل، افتح بريدك وأكّد الحساب من الرسالة اللي بتوصلك.

---

## الخطوة 2: اعمل مشروع جديد

1. بعد الدخول بتوصل لصفحة اسمها **Dashboard**. اكبس **New project**.
2. إذا سألك عن **Organization**: اختار اللي باسمك (بينعمل لحاله أول مرة).
3. عبّي:
   - **Name (اسم المشروع):** `samia-appointments`
   - **Database Password (كلمة سر قاعدة البيانات):** اكبس **Generate a password** واحفظها بمكان آمن (مثلاً بمدير كلمات السر أو دفتر). **رح نحتاجها لاحقاً بالمرحلة 1**، ومش ممكن نشوفها مرة ثانية.
   - **Region (المنطقة):** اختار الأقرب جغرافياً. مثلاً **Central EU (Frankfurt)**.
   - **Pricing Plan:** تأكد إنه **Free**.
4. اكبس **Create new project**.
5. انتظر دقيقة أو اثنتين لحد ما يخلص التجهيز (بتشوف شريط تحميل وبعدين لوحة المشروع).

---

## الخطوة 3: انسخ الرابط والمفتاح

1. من القائمة اليسارية (تحت)، اكبس على أيقونة **الترس** ⚙ اسمها **Project Settings**.
2. اكبس **API** (أو **API Keys**، حسب نسخة الموقع).
3. بتشوف إشيين مهمين:

| شو تنسخ | وين تحطه بملف `.env` |
|---|---|
| **Project URL** — رابط بيبلّش بـ `https://` وبيخلص بـ `.supabase.co` | `VITE_SUPABASE_URL=` |
| **anon public** (أو **Publishable key**، بيبلّش بـ `sb_publishable_`) | `VITE_SUPABASE_ANON_KEY=` |

   جنب كل قيمة في زر **Copy** بينسخها.

4. افتح ملف `.env` بمجلد `samia-app` بأي محرر نصوص، وحط القيم بعد علامة `=` بدون مسافات، مثل:

```
VITE_SUPABASE_URL=https://abcdefghijklmnop.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_xxxxxxxxxxxxxxxxxxxx
VITE_PUBLIC_BASE_URL=http://localhost:5173
```

> **تحذير مهم:** بنفس الصفحة في مفتاح ثاني اسمه **service_role** أو **Secret key** (بيبلّش بـ `sb_secret_`). **لا تنسخه ولا تحطه بأي مكان بالتطبيق.** هاد المفتاح بيفتح كل البيانات بدون أي حماية، ومكانه الوحيد لاحقاً بأسرار Supabase نفسها (للزوم والتنبيهات)، ورح أشرح وقتها.

---

## الخطوة 4: سكّر التسجيل الجديد

هاد التطبيق لسامية بس. لازم ما حدا يقدر يعمل حساب جديد.

1. من القائمة اليسارية اكبس **Authentication** (أيقونة الأشخاص).
2. اكبس **Sign In / Providers** (أو **Providers**).
3. اكبس على **Email**.
4. تأكد إنو **Enable Email provider** مفعّل (أخضر).
5. **طفّي** الخيار **Allow new users to sign up**.
6. اكبس **Save**.

> حساب سامية رح نعمله بإيدنا من لوحة Supabase بالمرحلة 1 (Authentication ← Users ← Add user). مش هلأ.

---

## الخطوة 5: جرّب الاتصال

1. بالـ Terminal، جوا مجلد `samia-app`، شغّل:
   ```
   npm run dev
   ```
   (إذا كان شغال من قبل، وقّفه بـ `Ctrl + C` وشغّله من جديد عشان يقرأ ملف `.env`).
2. افتح **http://localhost:5173**.
3. ببطاقة **حالة التجهيز** لازم تشوف "موجود" جنب الثلاث قيم.
4. اكبس **جرّب الاتصال بـ Supabase** ← لازم يطلع **"الاتصال بـ Supabase شغال"**.

إذا طلع خطأ:

| الرسالة | السبب المحتمل | الحل |
|---|---|---|
| "ناقص" جنب قيمة | ملف `.env` مش موجود أو القيمة فاضية | راجع الخطوة 3، وتأكد إنو اسم الملف `.env` بالضبط |
| "المفتاح مرفوض" | نسخت مفتاح غلط | انسخ **anon public / Publishable key** مرة ثانية |
| "ما قدرنا نوصل للرابط" | الرابط فيه غلطة أو ما في إنترنت | تأكد إنو الرابط يبلّش بـ `https://` ويخلص بـ `.supabase.co` بدون مسافات |

---

## لاحقاً (المرحلة 1): ربط Supabase CLI

مش لازم تعمل هاد هلأ. بس للمعلومة: بالمرحلة 1 رح نحتاج نرفع جداول قاعدة البيانات، وهاد بيصير بأوامر من الـ Terminal:

```
npx supabase login
npx supabase link --project-ref <معرّف-المشروع>
npx supabase db push
```

**معرّف المشروع (project ref)** هو الجزء اللي قبل `.supabase.co` بالرابط. مثلاً إذا الرابط `https://abcdefghijklmnop.supabase.co` فالمعرّف هو `abcdefghijklmnop`. أمر `link` رح يطلب **Database Password** اللي حفظتها بالخطوة 2.

---

## ملاحظة: المشروع المجاني بيتوقف بعد أسبوع بدون استعمال

إذا ما انستعمل المشروع أسبوع كامل، Supabase بيوقّفه (Pause). البيانات ما بتروح.
للرجوع: افتح https://supabase.com/dashboard ← اكبس على المشروع ← **Restore project** ← انتظر دقيقة.
