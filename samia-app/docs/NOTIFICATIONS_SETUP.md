# تفعيل التنبيهات على التلفون (Web Push) وملخص الصبح

التنبيهات بتوصل لتلفون سامية لما يجي وقت رسالة لازم تنبعت ("عندك 3 رسائل لازم تنبعت")، وكل صباح ملخص اليوم.
كل إشي مجاني: Supabase (`pg_cron` + `pg_net` + Edge Function) ومتصفح التلفون.

لازم تكون خلّصتي `SUPABASE_SETUP.md` ورفعتي قاعدة البيانات (`npx supabase db push`).

---

## الخطوة 1: ولّدي مفاتيح VAPID (مرة وحدة)

بالـ Terminal جوا مجلد `samia-app`:

```
npm run vapid
```

بيطلعلك سطرين:

1. **`VITE_VAPID_PUBLIC_KEY=...`** ← انسخيه وحطيه بملف `.env` (ولاحقاً بمتغيرات Cloudflare Pages).
2. **JSON طويل** ← هاد السر `VAPID_KEYS`، بينحط بـ Supabase بالخطوة 3. **ما تحطيه بملف `.env` ولا ترفعيه على Git.**

---

## الخطوة 2: انشري خدمة التنبيهات

```
npx supabase functions deploy notify-due --no-verify-jwt
```

(`--no-verify-jwt` لازم، لأنو الخدمة بتنادى من المجدول بسر خاص مش بتوكن مستخدم. الخدمة نفسها بتفحص السر.)

---

## الخطوة 3: الأسرار

افتحي **Supabase Dashboard ← Edge Functions ← Secrets** وأضيفي:

| الاسم | القيمة |
|---|---|
| `VAPID_KEYS` | الـ JSON الطويل من الخطوة 1 (سطر واحد كامل) |
| `VAPID_CONTACT` | إيميلك (مثلاً `samia@example.com`) |
| `CRON_SECRET` | كلمة سر طويلة عشوائية (مثلاً 32 حرف). اختاريها بنفسك واحتفظي فيها للخطوة 4 |

---

## الخطوة 4: فعّلي الجدولة (مرة وحدة)

1. بـ Supabase Dashboard ← **Database** ← **Extensions**: تأكدي إنو `pg_cron` و`pg_net` مفعّلين (ابحثي عنهم واكبسي Enable إذا مش مفعّلين).
2. افتحي **SQL Editor** ← **New query**، والصقي هاد (بدّلي القيمتين):

```sql
select vault.create_secret('https://<معرّف-المشروع>.supabase.co/functions/v1/notify-due', 'notify_due_url');
select vault.create_secret('<نفس CRON_SECRET من الخطوة 3>', 'cron_secret');
```

3. اكبسي **Run**. خلص: المجدول بينادي الخدمة كل 5 دقايق.

> للتأكد إنو المجدول شغال: SQL Editor ← `select * from cron.job;` لازم تشوفي سطر اسمه `notify-due`.
> ولشوف آخر التشغيلات: `select * from cron.job_run_details order by start_time desc limit 10;`

---

## الخطوة 5: فعّلي التنبيهات على التلفون

### آيفون (iOS 16.4 وأحدث)
1. افتحي رابط التطبيق بـ **Safari**.
2. اكبسي زر **المشاركة** (المربع مع السهم لفوق) ← **إضافة إلى الشاشة الرئيسية** ← **إضافة**.
3. افتحي التطبيق **من الشاشة الرئيسية** (مش من Safari).
4. **الإعدادات** ← **التنبيهات على التلفون** ← **فعّلي التنبيهات** ← اسمحي.
5. اكبسي **ابعتي تنبيه تجريبي** ← لازم يوصل تنبيه.

### أندرويد
1. افتحي الرابط بـ **Chrome**.
2. **الإعدادات** ← **فعّلي التنبيهات** ← اسمحي.
3. (مستحسن) من قائمة Chrome (النقاط الثلاث) ← **تثبيت التطبيق**.

### الكمبيوتر
نفس الخطوات من Chrome أو Edge. كل جهاز لازم يتفعّل لحاله.

---

## إشعار لما الزبون يرد

- لما الزبون يكبس **موافق** أو **بدي أغيّر** أو **ما بقدر أجي** بصفحته، بيوصلك خلال ثواني: "ليلى: موافق. جلسة زوم الثلاثاء 28/10 الساعة 16:00."
- بيبيّن الاسم الأول بس. ملاحظة الزبون على طلب التغيير ما بتطلع بالإشعار، بتشوفيها بصفحة الموعد.
- الكبسة على الإشعار بتفتح صفحة الموعد. إذا الزبون غيّر رده، الإشعار الجديد بيحل محل القديم.
- إذا ما في تلفون مفعّل وقت الرد، الإشعار بيوصل أول ما تفعّلي (لحد 6 ساعات بعد الرد).

---

## تنبيه قبل الجلسة

- قبل كل جلسة بنص ساعة بيوصل: "عندك جلسة الساعة 16:00، بعد نص ساعة." (بدون اسم الزبون، عشان شاشة القفل).
- بيوصل حتى لو رسالة التذكير للزبون انبعتت من قبل، ومرة وحدة لكل جلسة. إذا تغيّر وقت الجلسة بيوصل من جديد على الوقت الجديد.
- ما بيوصل للجلسات الملغية أو المرفوضة أو اللي خلصت.
- لتغيير المدة (مثلاً ربع ساعة) أو لتطفيه: SQL Editor ← `update public.settings set session_alert_minutes = 15;` (و`0` بيطفيه).

---

## ملخص الصبح

- من **الإعدادات ← ملخص الصبح** بتختاري الساعة (افتراضي 08:00 بتوقيت القدس) أو تطفّيه.
- بيوصل مرة وحدة باليوم، خلال 5 دقايق من الساعة المحددة (لأنو المجدول بيشتغل كل 5 دقايق).
- النص: "صباح الخير، اليوم عندك 3 جلسات، ورسالتين لازم ينبعتوا." وإذا ما في جلسات: "صباح الخير، ما عندك جلسات اليوم."

---

## إذا ما وصل تنبيه

| الوضع | شو تفحصي |
|---|---|
| "ما في أجهزة مشتركة" | ما فعّلتي التنبيهات على أي جهاز (الخطوة 5) |
| "السر VAPID_KEYS مش موجود" | الخطوة 3 |
| التنبيه التجريبي بيوصل بس التذكيرات لا | الخطوة 4 (المجدول). افحصي `cron.job_run_details` |
| على الآيفون ما في زر تفعيل | التطبيق لازم يكون مفتوح من الشاشة الرئيسية |
| التنبيهات وصلت وبعدين وقفت | يمكن المشروع المجاني توقف (Pause) بعد أسبوع بدون استعمال. رجّعيه من لوحة Supabase |
