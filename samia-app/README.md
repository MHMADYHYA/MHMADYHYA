# مواعيد سامية يحيى

تطبيق ويب بيشتغل على التلفون والكمبيوتر (PWA) لإدارة مواعيد جلسات **سامية يحيى**، عاملة اجتماعية ومعالجة.

- سامية بتعيّن موعد ← التطبيق بيجهّز رسالة واتساب ← بتكبس "ابعت" ← بيفتح الواتساب والرسالة جاهزة.
- الزبون بيوصله رابط خاص فيه 3 أزرار: **موافق / بدي أغيّر / ما بقدر أجي**، والحالة بتتحدث بالتطبيق لحالها.
- كل الجلسات أونلاين بالزوم، ورابط الزوم بينعمل تلقائياً.
- تذكيرات قبل الموعد بيوم وبساعة، صفحة "بدها متابعة"، متابعة الدفع لكل جلسة، وملخص كل صباح على التلفون.
- **كل إشي مجاني:** Supabase (قاعدة البيانات) + Cloudflare Pages (الاستضافة) + واتساب سامية الشخصي.

الخطة الكاملة بملف [`PLAN.md`](PLAN.md).

## قبل ما تبلّش: شو لازم يكون عندك

1. **Node.js** (النسخة 20 أو أحدث).
   - افتح [nodejs.org](https://nodejs.org) ونزّل نسخة **LTS** وثبّتها زي أي برنامج.
   - للتأكد: افتح **Terminal** (على Mac) أو **موجه الأوامر / PowerShell** (على Windows) واكتب:
     ```
     node -v
     ```
     لازم يطلعلك رقم مثل `v22.x.x`.
2. **حساب Supabase مجاني.** الشرح خطوة خطوة بملف [`docs/SUPABASE_SETUP.md`](docs/SUPABASE_SETUP.md). ما بيحتاج بطاقة ائتمان.

## كيف تشغّل التطبيق على الكمبيوتر

كل الأوامر بتنكتب بالـ Terminal، وإنت جوا مجلد `samia-app`.

1. **ادخل على مجلد المشروع:**
   ```
   cd samia-app
   ```
2. **نزّل المكتبات** (أول مرة بس، بتاخد دقيقة أو اثنتين):
   ```
   npm install
   ```
3. **اعمل ملف الأسرار.** انسخ `.env.example` باسم `.env`:
   - على Mac / Linux:
     ```
     cp .env.example .env
     ```
   - على Windows:
     ```
     copy .env.example .env
     ```
4. **عبّي القيم بملف `.env`** (افتحه بأي محرر نصوص). القيمتين الأولى بتجيبهم من Supabase حسب [الدليل](docs/SUPABASE_SETUP.md). الثالثة خليها زي ما هي محلياً. الرابعة (التنبيهات) بتتعبى لاحقاً.
5. **شغّل التطبيق:**
   ```
   npm run dev
   ```
6. افتح المتصفح على: **http://localhost:5173**

لتوقيف التطبيق: اكبس `Ctrl + C` بالـ Terminal.

> **ملاحظة:** إذا غيّرت إشي بملف `.env`، وقّف التطبيق وشغّله من جديد عشان يقرأ القيم الجديدة.

## كيف تجرّب

### قبل ربط Supabase
افتح http://localhost:5173/setup: صفحة فيها اللوجو والألوان وحالة ملف `.env` وزر "جرّب الاتصال بـ Supabase".

### بعد ربط Supabase ورفع قاعدة البيانات وعمل الحساب
- [ ] **تسجيل الدخول** بالإيميل وكلمة السر ← بتفتح صفحة التقويم مع التحية "صباح الخير، سامية".
- [ ] **الزبائن** ← "زبون جديد" ← اسم ورقم (مثلاً `0501234567`) ← بيظهر بالقائمة والرقم محفوظ بصيغة دولية.
- [ ] **زر +** ← اختار الزبون، التاريخ والساعة ← "احفظ" ← بتفتح صفحة الموعد وفيها زر "ابعت للزبون".
- [ ] "ابعت للزبون" ← بيفتح الواتساب والرسالة جاهزة فيها رابط الرد. اكبس إرسال بالواتساب (أو ابعتها لنفسك للتجربة).
- [ ] افتح رابط الرد من التلفون ← صفحة فيها "مرحبا {الاسم}" و3 أزرار ← "موافق" ← الحالة بالتطبيق بتصير "موافق" لحالها.
- [ ] موعد ثاني بنفس الوقت ← رسالة "في موعد ثاني بنفس الوقت: {اسم} {ساعة}".
- [ ] **غيّر الموعد** ← رسالة تغيير فيها القديم والجديد، والحالة بترجع "بانتظار رد".
- [ ] **ألغي** ← رسالة إلغاء، ورابط الزبون بيوريه "الجلسة ملغية".
- [ ] موعد مرق وقته ← "حضر" ← بيطلع بـ **الدفعات** ← "دفع" ← اختار "بيت" ← المبلغ بينضاف لملخص الشهر.
- [ ] **الرسائل**: التذكيرات بتطلع لما يجي وقتها (قبل بيوم وقبل بساعة)، مع "ابعت" و"تعلّمت كمبعوتة" و"تخطّي".
- [ ] **الإعدادات**: عدّل قالب رسالة وشوف المعاينة، فعّل التنبيهات (بعد `NOTIFICATIONS_SETUP.md`)، صدّر البيانات.

## الأسرار والخصوصية

- المفاتيح وكلمات السر بملف **`.env` فقط**، وهاد الملف **ما بينرفع على Git** أبداً (موجود بـ `.gitignore`).
- الواجهة بتستعمل مفتاح `anon` بس. مفتاح `service_role` (Secret key) ومفاتيح الزوم والمفتاح الخاص للتنبيهات بينحطوا بأسرار Supabase بس.
- RLS مفعّل على كل الجداول: بس حساب سامية بيقرأ أو بيكتب. الزبون بيشوف صفحته عن طريق توكن طويل عشوائي ودالتين محدودتين بس، بدون أي معلومة ثانية.
- الرسائل وعنوان اجتماع الزوم فيهم كلمة "جلسة" بس، بدون أي تفاصيل علاجية. الدفع ما بيظهر أبداً للزبون.
- ما في أي أدوات تتبّع أو إحصائيات خارجية. الخط (Alexandria) محمّل مع التطبيق نفسه.
- هاد تطبيق لمعالجة: الملاحظات للأمور التنظيمية بس، مش لملاحظات علاجية.
- **نسخة احتياطية:** الخطة المجانية لـ Supabase ما فيها نسخ احتياطية تلقائية. من **الإعدادات ← تصدير البيانات** نزّلي ملفات CSV كل فترة.

## ملاحظة مهمة عن Supabase المجاني

المشروع المجاني بـ Supabase **بيتوقف (Pause) إذا ما انستعمل أسبوع كامل.** مع استعمال يومي ما في مشكلة.

إذا توقف:
1. افتح [supabase.com/dashboard](https://supabase.com/dashboard).
2. اكبس على المشروع.
3. اكبس **Restore project** وانتظر دقيقة أو اثنتين.

البيانات ما بتروح، بس التطبيق ما بيشتغل لحد ما ترجّعه.

## ملاحظات للمطوّر

- `node e2e/screens.mjs <مجلد>` بيفتح كل الشاشات ببيانات تجريبية (محاكاة Supabase جوا المتصفح) وبيصوّرها. بيحتاج Playwright (`PLAYWRIGHT_PATH` إذا مثبّت بمكان ثاني).
- Edge Functions مكتوبة لـ Deno؛ المنطق الصافي بمجلد `supabase/functions/_shared/` وبينختبر بـ Vitest.
- التقويم (FullCalendar) بيشتغل بوضع UTC ومنطعمه أوقات "ساعة الحائط" بتوقيت القدس (انظر `src/lib/dates.ts`)، عشان ما نحتاج مكتبة مناطق زمنية.
